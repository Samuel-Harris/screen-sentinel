[Gemini CLI](https://github.com/google/gemini-cli) is Google's terminal-based AI coding assistant. it supports MCP servers, so you can connect Screen Sentinel to give Gemini context about what you've been working on.

## setup

Gemini CLI uses MCP for external tools. add Screen Sentinel to your config:

```bash
# add screen-sentinel MCP server
gemini config mcp add screen-sentinel "npx -y screen-sentinel-mcp"
```

or edit your config file directly:

```json
{
  "mcpServers": {
    "screen-sentinel": {
      "command": "npx",
      "args": ["-y", "screen-sentinel-mcp"]
    }
  }
}
```

restart Gemini CLI after configuration.

## usage

once configured, Gemini can search your screen history:

```bash
gemini

> what was I working on this morning?

> find the error message I saw in my terminal earlier

> summarize the documentation I was reading about kubernetes
```

## available tools

Screen Sentinel provides these MCP tools to Gemini:

- **search-content** - search accessibility-first screen text, audio transcriptions, and input events
- **export-video** - create video exports from screen recordings

## example workflows

**context-aware coding:**
```
> I was looking at a react component earlier that handled
> form validation, find it and help me implement something similar
```

**debug from memory:**
```
> there was an error in my build output, find it and help me fix it
```

**recall documentation:**
```
> what did that API documentation say about rate limits?
```

## requirements

- Screen Sentinel running on localhost:3130
- Gemini CLI installed
- Node.js >= 18.0.0
